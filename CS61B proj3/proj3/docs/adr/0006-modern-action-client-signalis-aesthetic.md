# ADR-0006: 实时 Action 客户端与 SIGNALIS 复古工业美学渲染

## 背景与上下文

在完成 3C 无状态重放内核后，现有的浏览器客户端仅具备简单的单步网格重放与纯字符绘制能力。为了将项目打造为符合现代商业化标准的 2D 独立游戏客户端（作为简历核心亮点），需要对客户端的表现层、主循环、战斗系统与视觉管线进行现代化重构。

## 架构决策

1. **时钟与主循环（Game Loop）**：
   - 采用 60FPS 实时时钟模型，解耦逻辑帧（FixedUpdate）与渲染帧（Render）。
   - 角色移动采用连续平滑插值（Lerp），摆脱逐格瞬间闪烁。
2. **纯原生 Canvas 2D 自研渲染管线**：
   - 放弃重型第三方框架，采用原生 HTML5 Canvas 2D 构建多层绘制管线（地形底图层、实体层、光影迷雾层、雨水天气层、CRT 后处理滤镜层）。
   - 实现纯像素风特效引擎（Pixel Particle Emitter），所有弹道、砍击、火花、雨滴均保证纯正像素颗粒感。
3. **SIGNALIS 复古工业科幻美学（Art Direction）**：
   - 主菜单采用暗红/亮橙与深黑的高对比度排版，包含像素机械眼眸插画、CRT 扫描线（Scanlines）与中英/德双语硬核框线。
   - 游戏中引入全屏像素十字准星与雨天模式（可选倾斜像素雨滴与地面水花）。
4. **即时战斗与探索机制**：
   - 玩家使用鼠标独立瞄准射击白黄双色粒子光束；
   - 地图怪物具备 A* 智能索敌移动与绿色半月形弧光挥砍攻击；
   - 道具系统包含可拾取火把（动态扩大迷雾视线光晕）、红色回血药水与金色攻击力强化水晶；
   - 像素 HUD 包含分段爱心血量槽（Heart Containers）与状态信息。
5. **范围约束**：
   - 不引入音频引擎，专注于顶尖的视觉手感与渲染管线呈现。
