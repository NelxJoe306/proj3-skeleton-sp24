# ADR-0006: 60FPS 实时动作客户端与 SIGNALIS 工业复古美学渲染管线

## 决策背景

在 3C 基础版（基于每键无状态重放的步进模式）之上，为了将本项目提升为高完成度、现代商业级标准的 2D 独立游戏客户端，并能够作为强力简历展示作品，需要在视觉、手感、战斗系统与渲染管线上进行全面升级。

## 核心架构决策

1. **双时钟渲染主循环与即时制（Action RPG）状态机**：
   - 客户端采用 60FPS requestAnimationFrame 主循环，将 FixedUpdate（60Hz 逻辑步进：碰撞、弹道、怪物 AI）与 Render（支持平滑渲染插值）解耦。
   - 状态机包含：MENU（主菜单）、PLAYING（游戏进行中）、PAUSED（暂停）、GAME_OVER（死亡）、VICTORY（过关结算报告）。
2. **SIGNALIS 工业复古美学（Retro Sci-Fi Aesthetic）**：
   - 视觉体系采用暗红、亮橙与纯黑的高对比度单色工业排版。
   - 主菜单以经典机械义眼为核心（带微弱呼吸光晕、瞳孔动态反光与 CRT 故障 Glitch）。
   - 全局后处理层：自研像素级 CRT 扫描线（Scanlines）与像素十字准星。
3. **分层 2D 渲染管线与光照/迷雾（Layered Tilemap & Fog of War）**：
   - 分层绘制：0-地形层，1-装饰与掉落物，2-实体层（Y-Sort 遮挡排序），3-动态光影与战争迷雾，4-像素粒子特效，5-全屏天气后处理（雨天模式），6-像素 HUD。
   - 迷雾与光照：未探索全黑、记忆区暗灰、视线内全亮。玩家携带基础光照半径，探索拾取火把后显著扩大视野光照范围。
4. **像素风战斗与视觉反馈（Game Juice）**：
   - 主角攻击：鼠标指向发射白黄混杂的能量粒子光束。
   - 怪物攻击：A* 智能追踪怪物，近战挥出绿色弧光月牙刀光（Slash VFX）。
   - 反馈机制：受击白闪（Hit Flash）、屏幕震动（Screen Shake）、伤害抛物线飘字（Floating Numbers）。
   - 道具：红色像素血瓶（补血）、金色攻击水晶（增伤），走位自动拾取。
   - HUD：左上角像素红心槽，右上角状态仪表盘。
5. **纯原生 Canvas 2D 自研实现**：
   - 保持零第三方前端依赖，所有粒子、光照、扫描线、动画均由纯原生 Canvas 2D 算法驱动。

## 影响与收益

- 与底层 Java 确定性世界生成（Structure Layer）完美互补；
- 极大增强客户端表现力、流畅手感与工程深度，达到独立游戏级别的完整度。
