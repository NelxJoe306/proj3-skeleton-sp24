# 03: 动态战争迷雾与可拾取火把光晕系统

**What to build:** 构建 2D 动态战争迷雾与可拾取火把系统。初始状态下玩家仅拥有微弱近距视线（其余区域全黑遮罩与暗色记忆），拾取地牢中散落的火把道具后，动态光源半径大幅扩大并产生像素级摇曳光晕。

**Blocked by:** 02: continuous-game-loop-and-lerp-camera

**Status:** ready-for-agent

- [ ] 多层渲染管线合成黑色未探索迷雾与半暗已探索记忆区域
- [ ] 地牢中随机散落像素火把道具，玩家走上自动拾取
- [ ] 拾取火把后玩家光源半径显著扩大（如从 3 格扩大至 8 格）
- [ ] 光晕具有随距离平滑衰减的柔和像素质感与动态呼吸微晃动
