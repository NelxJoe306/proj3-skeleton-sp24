# proj3C 现代标准游戏客户端（SIGNALIS 工业复古美学 + 即时制像素战斗与动态光影）spec

> 遵循 `CONTEXT.md` 领域模型；遵守 ADR-0001（结构/表现分离）、ADR-0002（存档 = seed + 运行时快照）、ADR-0003（运行时零随机）、ADR-0004（stateless replay）、ADR-0006（实时 Action 客户端与 SIGNALIS 工业美学）。

## Problem Statement

现有的 3C Web 客户端是一个基础的单步重放原型：画面为字符网格、角色移动为网格跳变、按键依赖单步重放循环，缺乏现代商业级独立游戏客户端应有的视觉表现力、手感打击反馈、即时制动态战斗与沉浸式氛围。为了将本项目打造成可直接呈现在简历上的代表作，需要以现代 2D 游戏引擎架构为基准，将其全面重构成一个具备 **SIGNALIS 像素复古工业美学**、**60FPS 实时双时钟主循环**、**自研多层 Canvas 2D 渲染管线**、**动态光影迷雾**、**像素级粒子即时战斗系统** 与 **进阶平滑摄像机** 的现代游戏客户端。

## Solution

在原有 Java 无状态地图生成内核之上，将 Web 客户端重构为全功能的现代 2D 像素 Action 游戏引擎：
1. **主循环与运动模型（Game Loop & Motion）**：采用 `requestAnimationFrame` 驱动的 60FPS 双时钟模型（`FixedUpdate` 逻辑步进 + 渲染状态线性插值 `Lerp`），玩家在网格空间中自由平滑移动，告别单格瞬移。
2. **SIGNALIS 风格视觉体系（Art Direction & UI）**：
   - 工业复古高反差排版：暗黑底色、高亮橙红框线、德/英/中硬核双语标记、全屏 CRT 扫描线（Scanlines）与像素十字准星。
   - 主菜单：手绘质感机械巨眼像素插画（带微呼吸待机动画）、全宽功能选择栏（《 开始 》BEGIN / 《 读档 》LOAD / 《 模式 》MODE / 《 指南 》MANUAL）。
   - 结算画面：通关时弹出 SIGNALIS 风格的暗红黑战绩报告单（MISSION REPORT：用时、步数、击杀数、评级）。
3. **环境与光影系统（Lighting, Fog & Weather）**：
   - **动态战争迷雾（Fog of War）**：基础视野受限，未探索区域全黑遮罩，已探索区域留存暗度记忆。
   - **火把系统（Torch & Dynamic Lighting）**：地牢中散落可拾取的火把道具；拾取后玩家光照半径显著扩大，并伴随像素级动态摇曳光晕。
   - **雨天模式（Rainy Weather Mode）**：可选环境天气开关，全屏实时生成倾斜下落的像素雨滴粒子，并在地面产生微小像素水花（Splash）。
4. **即时战斗与像素粒子系统（Combat & Pixel VFX）**：
   - **主角远程攻击**：鼠标移动瞄准，左键/长按朝准星发射白黄双色混合的像素能量光束，击中墙壁产生火花，击中怪物触发受击白闪（Hit Flash）与伤害飘字。
   - **怪物近战 AI**：怪物根据实时时钟进行 A* 智能索敌移动，近身时挥出绿色像素半月形刀光砍击（Green Slash VFX），命中玩家扣减血量并伴随轻微屏幕震动（Screen Shake）。
   - **道具掉落**：地图上生成红色回血药水（恢复红心）与金色攻击力水晶（提升弹道伤害与射速），玩家走过自动拾取并弹出像素提示。
5. **现代像素 HUD**：左上角经典像素红心生命值槽（Heart Containers）、火把持有状态与攻击力数值指示。
6. **进阶摄像机系统（Cinematic Camera）**：平滑阻尼跟随玩家、死区检测（Deadzone）、全图/特写滚轮缩放、边界限制（Clamping）与打击震动衰减。

## User Stories

### 主菜单与视觉风格
1. 作为玩家，我希望在启动游戏时看到充满 SIGNALIS 风格的暗黑复古工业科幻主菜单，包含醒目的机械眼插画与 CRT 扫描线，以获得强烈的沉浸式独立游戏体验。
2. 作为玩家，我希望主菜单提供《 开始 》BEGIN、《 读档 》LOAD、《 模式 》MODE、《 指南 》MANUAL 等功能选项，并支持清晰的高亮切换。
3. 作为玩家，我可以在主菜单或游戏中切换【雨天模式】，看到倾斜飘落的像素雨滴和地面水花效果。

### 摄像机与移动手感
4. 作为玩家，我希望使用 WASD 进行丝滑的无级平滑移动，而不是生硬的一格一格瞬移。
5. 作为玩家，我希望摄像机能够以阻尼插值平滑跟随角色，并在小范围挪动时保持死区稳定，在激烈碰撞时产生轻微屏幕震动。
6. 作为玩家，我希望可以通过鼠标滚轮在“全图鸟瞰”与“贴地特写”之间自由缩放视口。

### 光影、火把与迷雾探索
7. 作为玩家，我希望游戏初始具有压迫感的暗黑战争迷雾，未探索的区域全黑，只有角色周围小范围可见。
8. 作为玩家，我希望在地牢中寻找并拾取火把，拾取后瞬间大幅扩大我的动态光源视野，照亮更大范围的房间和走廊。
9. 作为玩家，我希望动态光源具有随距离衰减的柔和光晕，且光影具有像素颗粒质感。

### 战斗、粒子特效与 AI
10. 作为玩家，我希望屏幕上有一个跟随鼠标的像素十字准星，当我点击鼠标左键时，能够朝准星方向射出白色与黄色交织的像素粒子光束。
11. 作为玩家，我希望子弹命中墙壁时产生像素碎屑火花，命中敌人时触发受击白闪、顿帧和抛物线伤害飘字。
12. 作为玩家，我希望地图中的怪物具有巡逻与追逐 AI，当接近我时会挥出绿色的半月形像素砍击刀光。
13. 作为玩家，当受到怪物攻击时，我的血量减少，且屏幕产生短促的红屏微震反馈。

### 道具、成长与 HUD
14. 作为玩家，我希望在地牢中能拾取到红色血瓶以恢复爱心血量，拾取到金色攻击水晶以强化我的射击伤害与频率。
15. 作为玩家，我希望左上角有直观的像素红心 HUD 实时显示当前生命值。
16. 作为玩家，我希望走过道具时能够自动拾取，无需按多余键位，并伴有向上浮动的像素文字提示（+HP, +ATK）。

### 终点过关与战绩结算
17. 作为玩家，我希望在清理怪物与探索地牢后，找到深处的传送目标格（★），踏上后达成胜利。
18. 作为玩家，我希望通关时展示 SIGNALIS 风格的通关数据报告面板（耗时、步数、击杀数、评级），并提供返回主菜单按钮。

## Implementation Decisions

1. **架构分层（Decoupled Client Engine）**：
   - 保持后端 Java 世界生成与静态结构（`WorldGenerator`）完全独立。
   - 前端采用模块化设计：
     - `engine.js`：60FPS Game Loop（FixedUpdate 60Hz + Render Interpolation）、输入映射（WASD + Mouse Aim）。
     - `camera.js`：带有 Lerp 跟随、Deadzone、Screen Shake 震动衰减与 Clamping 视口计算。
     - `renderer.js`：多层 Canvas 2D 绘制管线（Layer 0: 地面; Layer 1: 道具与火把; Layer 2: 玩家与怪物; Layer 3: 砍击与射击粒子; Layer 4: 动态光照迷雾混合遮罩; Layer 5: 雨水粒子; Layer 6: CRT 扫描线与 HUD）。
     - `combat.js`：投射物系统（白黄双色粒子束）、近战刀光系统（绿色弧光）、碰撞检测、伤害计算与飘字。
     - `ai.js`：怪物状态机（Patrol/Chase/Attack）与 A* 简化寻路。
     - `lighting.js`：2D 径向光源与像素迷雾遮罩合成（`globalCompositeOperation = 'destination-out'`）。
     - `weather.js`：倾斜像素雨滴发射器与落地水花粒子。
     - `ui.js`：SIGNALIS 风格机械眼插画绘制、主菜单 DOM/Canvas 状态机、爱心 HUD 与战绩结算报告。
2. **像素特效与色彩规范（Pixel Art Palette）**：
   - 界面主色调：SIGNALIS 工业橙红（`#ff4d26`）、深邃冷黑（`#0a0b0e`）、警示灰白（`#e0e6ed`）。
   - 玩家弹道：高亮纯白核心（`#ffffff`） + 能量亮黄外晕（`#ffe600` / `#ffb700`）像素方块粒子。
   - 怪物挥砍：剧毒/故障亮绿半月弧光（`#00ff66` / `#00cc44`）。
   - 道具：像素红心药水（`#ff2a4b`）、攻击力水晶（`#ffcc00`）、火把（`#ff8800` 摇曳动态光源）。
3. **零外部音频与零构建依赖**：
   - 不依赖任何 Webpack/Vite 编译链与第三方 CDN，纯原生现代 JavaScript（ES Modules）编写，直接双击或通过静态服务极速加载。
   - 不引入音频相关逻辑，全情聚焦于顶尖的渲染管线、粒子物理与视觉打击感。

## Testing Decisions

1. **测试原则**：
   - 保持后端已有的 84 个 Java 单元与集成测试（3A/3B/3C 核心）100% 保持全绿，作为安全网护栏。
   - 客户端建立轻量级无头行为测试与视觉验证脚本。
2. **测试卫生**：
   - 所有测试不依赖真实浏览器窗口，可在 Node/浏览器控制台中自测断言。

## Out of Scope

- **音频与音乐引擎**：明确排除 Web Audio API 音效，保证零外部音频资产依赖与纯粹的视觉管线呈现。
- **多人联机 WebSocket**：本期专注于极致的单人客户端表现力与手感，多人联网留待后续迭代。
- **后端数据库与账户系统**：继续复用无状态会话与 `save.txt`，不引入外部数据库。
