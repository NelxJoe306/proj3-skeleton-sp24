# 01 — 入参校验：非法 seed 字符串 → 明确异常

**What to build:** `getWorldFromInput` 的输入边界先行立住：只接受形态为 `N<数字>S` 的 seed 字符串（大小写不敏感）；对缺失 `N`/`S`、数字段非整数、多余字符等畸形输入，抛出带清晰信息的异常，而不是静默返回或产生难以理解的行为。这保证后续所有生成票面对的都是已校验的输入。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 畸形输入（无 `S`、无 `N`、数字段含非数字/空、空串/null）→ 抛信息明确的异常
- [ ] 允许并忽略 `N…S` 之后的字符（将来 3B 的移动/存档指令占位）
- [ ] 调用过程 headless，不触碰任何图形/渲染/StdDraw
- [ ] 大小写两种写法都能进到同一解析路径（与 02 的确定性测试呼应）
