# 05 — BSP 房间：递归分区产出矩形 room

**What to build:** 用 **BSP 递归分区**生成结构层的第一块实体：把画布按随机分割点递归二分到目标叶子尺寸，每片叶子落一个矩形 room（墙围地板）；多个独立房间并存，房间与画布边界之间保留墙/void 边距（边界无地板）。本票只做房间，不做房间之间的走廊。房间的随机参数全部来自 seed 单一 RNG（继承 03）。

**Blocked by:** 03 — 内容随 seed 变化

**Status:** ready-for-agent

- [ ] 世界含多个矩形 room（墙围起来的地板块，可从返回网格识别）
- [ ] 边界一圈无 floor
- [ ] 房间分布/尺寸随 seed 变化，且同 seed 完全复现
- [ ] room 之间当前是独立的（连通性由 06 负责，本票不要求）
