# 02 — 确定性最小管道（tracer bullet）

**What to build:** 打通从 seed 到 world 的第一条完整纵切：`getWorldFromInput` 解析合法 seed（大小写均可）后返回一张固定尺寸的 `TETile[][]`，现在内容可以很朴素，但**同 seed 每次调用逐格相等**、headless 可跑。同时立起内部分层骨架：一个负责"从 seed 构建结构"的入口与一个纯值世界概念分离，为 05–07 的结构票留位。

**Blocked by:** 01 — 入参校验

**Status:** ready-for-agent

- [ ] `N<数字>S` 与 `n<数字>s` 返回相同网格
- [ ] 同 seed 调用两次，网格逐格全等（确定性）
- [ ] 返回的网格尺寸固定且符合约定（默认 80×80，常量可调）
- [ ] 全程无渲染/图形副作用
- [ ] 内部已存在清晰的"结构构建"分层（后续房间/走廊票在此之上增量，不需重排骨架）
