# ADR-0005: 存档带尺寸行；goal 推导不存档

3C 让世界尺寸成为会话级参数（小/中/大，New Game 时选定），而 **seed 定不出尺寸**——ADR-0002 的 V1 存档（seed + avatar 坐标）不足以重建非默认尺寸的世界。决定：**存档格式保持 `V1` 头，只在非默认 80×80 的世界里追加一行 `size=宽x高`**；读档时缺省该行 ⇒ 视为默认 80×80。这样中档（遗留 seam 的默认）写盘内容与今天**逐字节相同**（现有 `SaveQuitTest.saveFileIsWrittenInV1Format` 类断言继续成立），"版本高于 V1 视为无档"的拒读语义（`aVersionAboveV1SaveIsTreatedAsNoSave`）也原样保留。另外，过关目标 **goal 不占存档**：位置是 (seed, size) 的纯函数（盖在最晚生成房间中心），读档由尺寸重建后重新推导即可；赢态同理可推（avatar 格 == goal 格），无需单独字段。取舍：运行时快照保持极简（仍只有 avatar），存档等价测试在任意尺寸下天然成立；代价是 goal 摆放规则必须**永远保持 (seed, size) 确定性**（ADR-0003 的延伸），改动摆放 = 旧档读出的关卡布局随之改变，需回本 ADR 复议。
